# kursa4
# 🏠 Веб-приложение для риэлторской конторы

**РИЭЛТ-ГАРМОНИЯ** — современный сайт-визитка для риэлторской компании, позволяющий просматривать каталог недвижимости, фильтровать объекты и отправлять заявки.

---

## ✨ Особенности

- 📱 **Адаптивный дизайн** — корректно отображается на мобильных устройствах и планшетах
- 🎨 **Современный UI** — градиенты, тени, hover-эффекты, анимации
- 🧩 **Карточки объектов** — с фото, ценой, адресом
- 🔍 **Фильтрация по типу и цене** — для быстрого поиска
- 📩 **Форма обратной связи** — для связи с агентами
- 📁 **Локальные изображения** — без внешних зависимостей

---

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стили, адаптивность, анимации
- **JavaScript** — логика фильтрации и интерактивности
- **Bootstrap 5** — сетка, компоненты, адаптивность
- **Montserrat** — шрифт
